01How it works

One loop, five hops, zero effort

You type. The AI writes a command. The extension runs it in your game and feeds the result back. Repeat — all automatically.

  1. 1

    You ask

    "Find every remote with Damage in the name."

  3. 3

    Extension runs it

    ZeroReal detects the block and forwards it to the bridge.

  4. 4

    The local MCP server runs it in your injected client.

04Install

Running in 5 minutes

  1. Open everything

    Real app (MCP server on) → Roblox → inject Real → join a game. Windows + Python 3.10+ required.

  2. Get the project

    git clone https://github.com/Ryanabcraft/zeroreal.git

  3. Start the bridge

    Double-click bridge/start-real.bat and leave the window open. It installs its own dependencies and syncs Real's port + token automatically — even if Real rotates them.

  4. Load the extension

    edge://extensions → Developer mode → Load unpacked → pick the extension/ folder.

  5. Start the agent

    Open a new chat (e.g. DeepSeek), click ▶︎ Start Real agent on the bar, and ask for something: "list the players with HP and position".

05FAQ

Troubleshooting

Grey dot / "Bridge offline" — what now?

start-real.bat isn't running. Launch it and keep the window open, then hit ↻ Reconnect in the extension popup.

"Real not connected · inject Real in a game" — but I injected!

Make sure you're inside a game (not the Roblox menu) with an injected client. The bridge re-discovers Real on every tool list — just press Start again.

The AI says the bridge is offline. Is it?

Probably a momentary reconnect. The agent is instructed to retry a fresh command before declaring anything offline — tell it "try again".

A tool spins forever. Stuck?

The client may be wedged (single-digit FPS kills everything). Re-inject, keep the game light, and prefer short commands.

Chrome updated and the page asks for a reload. Why?

Chrome auto-updates extensions under open tabs. Press F5 in the chat tab — bridge and Real are unaffected.

Is my Real token safe?

The bridge reads it from Real's own session files on your PC. It never leaves your machine — and the repo ships a config.example.json with no secrets.
